# Avatar Creator

A simple browser-based tool to design customizable pixel-style avatars and download them as PNG images.

## Features

- Customize background color
- Customize skin tone
- Customize hair color
- Choose between hair styles (Bowl Cut, Spiky, Bald)
- Randomize button for instant fun combinations
- Download your avatar as a PNG image

## How to run

1. Clone the repo
2. Navigate to this folder: `misc/avatar-creator/`
3. Double-click `index.html` to open it directly in your browser — no server needed.

## Tech used

- HTML
- CSS
- Vanilla JavaScript (SVG manipulation, Canvas API for PNG export)
