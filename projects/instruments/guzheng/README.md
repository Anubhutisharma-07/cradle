# Virtual Guzheng

A playable 21-string guzheng tuned to the D major pentatonic scale. Every
pluck is synthesized live with the Web Audio API — no audio samples.

## Controls

- **Keyboard:** `1234567890qwertyuiop[` (low to high, shown on each string)
- **Mouse:** click a string, or hold and drag across several to glissando
- **Touch:** tap a string, or swipe across several to glissando

## Run locally

Open `index.html` in a browser, or run `npm run dev` from the repo root.
